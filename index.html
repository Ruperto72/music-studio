Web Audio Studio — Help

Overview

A browser tool for composing 8-bit chiptune loops — everything is synthesised with the Web Audio API, no audio files. Instruments are laid out as separate tracks stacked vertically, like a music studio (Pro Tools style). A shared timeline at the top and the red playhead run across every lane at once. The current project's name is shown in the Master strip at the bottom (click it to rename while the strip is expanded) — the menu's Songs… loads an example, one of your own saved songs, or starts a new one; your own songs are stored in this browser.

Tracks & channel strips

  • Starts with a lane for each track in the loaded song (e.g. Lead, Harmony, Bass, …) plus at least one Rhythm lane with ten hit types: Kick, Snare, Rim, Hi-hat, Open hat, Shaker, Tom, Clap, Crash and Ride. Rhythm lanes always stay grouped after every tonal track.
  • Each track's channel strip (left) starts with its name, Mute / Solo, record-arm and remove, then three labelled sections: Osc (the waveform — or "Kit" for rhythm — plus the Auto/Env/Preset buttons), Inserts (the effect chips, see below) and Output (volume, pan and a level meter).
  • Add track / Add rhythm track (in the menu) add a tonal or rhythm track; double-click a track's name to rename it; the ✕ on a strip removes that track (the last remaining Rhythm lane can't be removed). Added tracks export into the game too.
  • The ▾/▸ button on a track collapses it to a slim strip — name, Mute/Solo and the level meter stay visible, everything else (waveform, automation/envelope, volume/pan, remove) hides along with the grid. Handy for an overview with many tracks. Remembered per browser.
  • A tonal track's left edge is a piano keyboard rather than a column of note names — white and black keys, with only C labelled, by its octave. Press a key to hear it, and drag down the keys to glissando; it sounds through the track's own instrument, so what you hear is what writing a note there would give you. A rhythm track keeps its ten piece names, since a drum has no pitch to show.
  • The Vel button opens a note lane under the track: one stem per note or hit, with a diamond head you can drag. The dropdown in its header picks which value it shows — Velocity, Pan, or Bend on a tonal track. Pan and bend are signed, so they grow from a centre line rather than from the floor: a stem reads as an offset from neutral, not as a quantity. The grid already dims a quiet item, but which of these is loudest is a comparison, and heights compare far better than shades of one colour. Works on rhythm tracks too — that is where accents matter most. Dragging a head to the top removes the velocity again rather than storing 100%, so a part you never touched saves exactly as it did before.
  • The Auto button opens a curve editor for that track's Volume, Pan, or Delay/Chorus/Reverb send over time (pick which from the dropdown): click empty space to add a point, drag a point to move it, double-click to delete it. Without any points, the channel strip's / FX panel's slider value is used for the whole song (as before).
  • The Env button opens that track's ADSR — Attack/Decay/Sustain/Release, shaping how a note's volume rises and fades — plus a per-track resonant lowpass filter (cutoff, resonance, and an envelope amount that sweeps the cutoff using the same ADSR shape). Tracks using the FM waveform get extra ratio/depth sliders here too, Ring gets the same ratio (how far above the note the modulator sits — a small whole number rings like a bell, anything else goes metallic), and tracks on Square get a Duty (pulse width) for the whole track. PWM is that same pulse width set sweeping — the width moves back and forth through each note, which is the sound that makes a chip lead sing rather than sit still. The sweep belongs to the track and runs continuously, so a run of short notes each picks it up where the last one left off instead of all starting at the same width — a single note can still override it from the inspector. Attack/Decay/Release are a percentage of each note's own length (so they scale with short vs. long notes); Sustain is the held level. Reset restores every default.
  • The Preset button saves a track's waveform, envelope, filter and FM settings as a named preset you can reuse on any tonal track, in any song (saved in this browser).
  • The Chords button (tonal tracks) writes a built-in chord progression into that track — I–V–vi–IV, Pachelbel's descent, the doo-wop turnaround, ii–V–I, the Andalusian cadence, the minor vamp, or a 12-bar blues — one chord per bar, from the playhead's bar to the end of the song, exactly like Patterns does for drums. The chords come from the song's Key: a progression is stored as scale degrees, so the same one is major or minor depending on the scale you picked. Change the key and insert it again to hear it somewhere else entirely. ▶ auditions it in the current key on that track's own sound before you commit.
  • ⧉ next to ✕ duplicates a track: a copy of the part and the whole voice — waveform, envelope, filter, inserts, sends, kit — placed directly below it. It's the quickest way to try the same line on another instrument, and the two parts are independent afterwards, so editing one doesn't touch the other.
  • A rhythm track has a Kit picker in its header — the same picker a tonal track uses for its waveform, in the same spot, each kit drawing the shape of its own decay: Retro (the tight, dry 8-bit kit — the default, and what every existing song keeps), 80s (a big gated snare, long crash, wide clap — the drum machine sound) and Acoustic-ish (lower, rounder kick and a snare with more skin in it). It is the same ten pieces throughout — the same rows, the same patterns, the same hits — synthesised with different numbers, so switching is instant and never touches what you've written. Each rhythm track picks its own, and the choice is saved with the song. Changing it auditions the snare, the piece a kit is easiest to judge by.
  • The Inserts section (every track, rhythm included) shows one chip per effect the track is using — a letter and an icon, so you can see what's on a track and what's bypassed at a glance. The knobs are not there: click a chip and the inspector column on the right shows that track's whole chain, every effect at once. (With nothing selected it shows it anyway — that column is the mixing surface.) + reveals an effect the track isn't using yet, Reset clears the lot. The effects are continuous Delay, Chorus and Reverb sends — a track-wide effect level, separate from the per-note Echo/Chorus/Reverb toggles in the note inspector — plus a 3-band EQ, a Compressor (threshold/ratio/attack/release, same controls as the master compressor), a Bitcrush knob (lo-fi downsampler, independent of the per-note Crush toggle) and a Tremolo (Rate/Depth — amplitude wobble, 0% depth is off). Tonal tracks also get a Vibrato (Rate/Depth in cents, 100 = a semitone) — pitch wobble on every note of the track, adding to the per-note Vibrato toggle rather than replacing it. Rhythm tracks don't offer it: it works by bending each note's oscillator, and a drum hit has none.
  • The Patterns button (rhythm tracks only) inserts a built-in groove — Rock, Techno, Disco, Swing, Hip-Hop, House, Breakbeat, Funk, Half-time, Bossa Nova, Reggae, Trap — tiled from the playhead's bar to the end of the song. Every hit carries its own velocity, so the backbeat lands full while the off-beat hats sit back: an accented groove rather than a flat machine pulse. Each pattern also has a fill bar, used on the last bar of each phrase — set how long a phrase is with Fill every (or turn fills off to get the same bar throughout), and the bar after a fill opens with a crash. The kit is also spread across the stereo field as it goes in — hi-hat and ride to the right, shaker, toms and crash to the left, kick and snare centred, so a pattern sounds like a kit in a room instead of ten sounds in one spot; Spread the kit in stereo turns that off. ▶ auditions the groove bar and ▶ fill the fill bar, exactly as they will be inserted, so you can hear both first. A pattern may bring a setting of its own along: Swing/Shuffle nudges the Swing slider, Funk switches the grid to 1/16 because that's where its ghost notes sit, and Trap to 1/16 T so its 16ths and its triplet roll are both readable.
  • Click a strip (or into its lane) to make it the active track that the tools edit.
  • Pitch lanes auto-fit to the notes they contain, so tracks stay compact.

Tools

  • Pen — click an empty cell to add a note/hit. Clicking a different pitch at the same time in a tonal track adds a chord tone, rather than replacing what's already there.
  • Eraser — click a note/hit to remove it (or a whole selected group).
  • Grab — drag a note/hit to move it; drag its right edge to change its length.
  • Timing in the menu quantizes or humanizes the selection — or the whole active track when nothing is selected. The point is the Strength slider: 100% lands every note dead on the grid, while 50% moves it halfway, which tightens a take without flattening the feel out of it. Humanize is the same operation in reverse, for a part that came out too stiff. This is why recording no longer snaps as you play — a take keeps the timing you gave it, and correcting it is a separate decision you can make with a strength rather than one the recorder makes for you.
  • Transpose in the menu is the same idea on the pitch axis, with the same scope rule. Semitone and Octave always work; with a Key set you also get Scale step, which moves each note to the next pitch in the key — so a melody nudged upward stays in the key instead of landing on the note between, and a chord moves to the next chord of the key rather than sliding sideways. Fit to the scale pulls everything onto the nearest scale tone: the repair a recorded take needs, since playing is never corrected on the way in. Two notes that would land on the same pitch in the same column never merge — the lower one moves and the other stays put, so fitting can't cost you a voice. The arrow keys use the same walk: with Keep to scale on, ↑/↓ move by a scale step and Alt+↑/↓ stay chromatic.
  • Dynamics in the menu is the third axis, with the same scope rule again. Vary is a random walk around each note's current level — a part you already shaped keeps its shape and just stops being mechanical about it, and pressing it again gives a different answer. Accent the beat plays the notes that land on a beat harder than the ones between them, read off the meter rather than guessed. Only velocity is touched: every note stays exactly where it is at exactly the pitch you put it, so trying one costs an undo at worst.
  • The Grid menu also has Free — placing, dragging and resizing stop snapping and land wherever you put them (on the app's finest lattice, a sixth of an eighth). The grid still sets how long a new note is, so Free changes where things go, not what size they are. It is remembered per browser rather than saved with the song: the same file opened by someone else should not silently stop snapping.
  • The Grid menu sets the snap resolution: 1/4, 1/8, 1/16, or triplets (1/8 T, 1/16 T). New notes take the grid length, and moving/resizing/nudging snaps to it — so you can place sixteenths and triplet figures between the eighth lines. Finer grids draw extra guide lines.
  • Placing or selecting a note/hit plays it, so you hear the pitch or drum as you edit.
  • Recording. Click R on a track to arm it — one track at a time, since there is one keyboard — and the letter keys become an instrument: ZSXDC… is the lower octave with the black keys on the row above, Q2W3… the octave up, and [/] shift the octave. On a rhythm track the same row plays the kit instead: Z is the kick through to / for the ride. Press Record and you get one bar of count-in, then everything you play lands on the grid at the current snap resolution. Stop ends the take. The Metronome button clicks on every beat, accented on the downbeat — it is a rehearsal aid only and never appears in an exported WAV.
  • Overdub. Turn Loop on before you hit Record and the transport keeps going round: the count-in happens once, and each lap adds to what is already there instead of replacing it. That is how a drum part or a riff actually gets built — one piece at a time over a bar you can hear. Playing the same pitch in the same place again replaces just that note, so you can fix one hit without losing the lap it sits in, and a key held through the seam becomes a note that runs to the end of the loop rather than a stab.
  • Step entry. With a track armed and the transport stopped, the same keys write into the song a step at a time: each one places a note at the playhead and moves it on one grid step, so you can type a part out at your own pace instead of playing it in time. Keys pressed together land as a chord on one column and the playhead moves once. → leaves a rest, ← goes back, ↑/↓ move to the track above or below, Home/End jump to the start of the song or the end of this track's part, and Backspace steps back and clears what's there. Every move is spoken with the position and what's already there (“bar 2 beat 3, C4, E4” / “empty”), so you can find your way around a part without seeing it — this is how you compose without a mouse at all.
  • Clicking a note or a drum hit opens it in the inspector on the right. A hit has Velocity (10–100%) — how hard it's struck, which is what turns a mechanical drum pattern into one with accents — and Pan. Velocity changes the tone as well as the level: a soft hit is darker, the way a real drum struck gently gives you less of the sharp top end, so a ghost note sits behind the beat instead of just being a quiet copy of the accent. Quieter notes and hits are drawn dimmer, so the accents are visible in the grid too. Notes have the same Pan slider: it places that one note or hit in the stereo field on top of whatever the track's own pan is doing, and double-clicking re-centres it. Panning the kit piece by piece — hi-hat off to one side, toms spread — is what stops a drum part sitting in a single spot.

Selecting several notes

  • Shift+click each note/hit to add or remove it from the selection (any tool).
  • With Grab, drag across empty space to marquee-select everything whose start falls in the range.
  • A selection moves together; Delete removes it; Ctrl/Cmd+C / V copies & pastes it at the playhead.

Note effects

Select a single note to edit vibrato, tremolo, bend, duty cycle, arpeggio, portamento, bitcrush, echo, chorus and reverb in the inspector on the right.

Two rows in the inspector offer the same ten chords — 5 (power chord), maj, min, dim, aug, sus2, sus4, 7, maj7 and m7 (hover a button for its full name). Click ▸ presets under Arpeggio or Chord to show them; they stay hidden until you ask, so the panel doesn't push the rest off-screen, and each remembers whether you left it open. They differ in what you get:

  • Arpeggio keeps one note and sweeps it through the chord's tones in quick succession — the classic chiptune way to imply a chord on a single voice. It fills in the Arpeggio box, which you can then edit by hand.
  • Chord adds the chord's other notes as real, separate notes above the selected one, in the same track and at the same length. They start with no effects of their own, so each can be tweaked afterwards.

With a Key set (bottom bar), the Chord row is led by two more buttons: the triad and the seventh chord this key builds on the selected note. They're labelled by degree — ii, V7 — rather than by quality, because which chords belong together is exactly what a key tells you, and ten absolute qualities are ten decisions for anyone who doesn't already know which one fits. The quality isn't written down anywhere: it's read off the scale, so the triad on the second degree of a major scale comes out minor because that's what the scale has there.

Bottom bar (Song · Tempo · Length · Key · Grid · Master)

The strip under the tracks holds the Song name (click it to rename), Tempo, Length, Key (the tonic and scale — see Transport & timeline), Grid (the note snap resolution) and the Master volume. The ▾ button collapses it to a slim bar to free up space (remembered between sessions) — the song name stays visible, but only rename-able while expanded. Length makes the song longer/shorter one bar at a time: + appends an empty bar, − removes the last bar (dropping any notes/hits past the new end); the length is saved with your file and exported so the game loops it.

Mixing

  • Each track's volume slider sets its relative level (its mix) — drag while playing to rebalance live.
  • The waveform picker in the Osc section — click it and a list drops down with each shape drawn as itself (Square / PWM / Triangle / Saw / Sine / Half sine / NES Tri wavetable / Noise / Ring / FM) — and the pan slider set each track's tone and stereo placement. Double-click the pan slider to re-center it.
  • Mute silences a track; Solo silences every track except the soloed one(s).
  • Master sets the overall preview loudness (editor only — not part of the game's audio).
  • The level meters (per track and next to Master) show live output while previewing or playing.
  • The Master FX button next to Master opens the Master FX panel: five chips — a 3-band EQ (Lo/Mid/Hi), a compressor (threshold/ratio/attack/release) with an optional parallel-comp blend, sidechain ducking on every kick/snare hit and a lo-fi downsampler — plus a live spectrum + approximate LUFS meter, which is always visible since it's a readout rather than a setting. A chip is dimmed while its effect is doing nothing, so you can see what's actually engaged. The knobs work exactly like a track's: click the Master cell (or any chip) and the whole master chain appears in the inspector on the right, all five groups at once. All on the master bus, post-FX.

Transport & timeline

  • Transport: return-to-start, stop, play, and a loop on/off toggle; the LCD shows Bars | Beats and Min:Sec.
  • Click the timeline (or drag the playhead) to set where playback starts; the view auto-scrolls to follow the playhead.
  • The green band is the loop range — drag its ends, or "Full range" to reset it. Repeat duplicates that range's notes/hits into the region right after it (growing the song if needed) and advances the range onto the copy, so clicking again keeps stamping it forward.
  • The Meter menu (bottom bar) sets the time signature (4/4, 3/4, 6/8, …), which regroups the bar lines, numbers and Length. Note times don't move.
  • The Key cell (bottom bar) sets the song's tonic and scale. Every row outside the scale is shaded in the piano roll and its key dimmed on the keyboard, and the tonic is marked — so you can see where the wrong notes are before you hear them. Nothing is forbidden: an out-of-scale row is still there and still clickable, because hearing the note you're avoiding is often the point. Keep to scale goes further and moves a note you place or drag with the mouse to the nearest pitch in the scale. It only affects the mouse — what you play is never corrected, the same way recording doesn't quantise as you play, and dragging several notes at once keeps the shape you're moving rather than pulling two of them onto one row. Key and scale are saved with the song; Keep to scale is a working preference remembered in this browser, so opening someone else's song doesn't change what your mouse does. Chromatic turns the whole thing off, which is what a song written before this existed loads as.
  • The flag button adds a marker at the playhead; click a marker flag to rename it (or clear the name to delete). Markers are saved with your file but aren't part of the game.

Saving & exporting

  • Songs… opens the Song library: load an example, one of your saved songs, or start a new song — named up front, either with the empty Lead/Harmony/Bass/Pad/Rhythm starter tracks or an empty project (just Rhythm). The project name lives in the Master strip at the bottom (click it to rename).
  • Save as .json / Load .json keep a work-in-progress .json (name, tracks, tempo, length, meter, mix, waveforms, pan, automation, envelopes & markers). Work also autosaves to this browser as a crash-recovery safety net — reloading the page always starts a fresh project with the starter tracks though, never auto-restoring that draft; pick a song explicitly via Songs… in the menu instead.
  • Export code emits the TRACKS and RHYTHM_TRACKS declarations to paste over the ones in audio.js; click it again to close the box.
  • Connect MIDI keyboard lets you play a real keyboard into the armed track — including how hard you press, which becomes the note's velocity (you hear it while playing, and it's drawn on the grid as brightness). Monitoring, recording and step entry all work the same as from the computer keyboard; on a rhythm track the notes map to the kit through General MIDI. It listens to every connected input on every channel, so there is nothing to choose. Needs a browser with Web MIDI (Chrome, Edge — not Safari).
  • Export MIDI / Import MIDI round-trip a Standard MIDI File — handy for moving note data to/from another DAW. Per-note effects, automation, ADSR/filter/FM and markers have no MIDI equivalent and aren't preserved.
  • Export WAV renders the whole song offline at 48kHz and downloads it as a .wav file.
  • Fullscreen toggles the browser's fullscreen mode. On Android, your browser's menu also offers Add to Home screen / Install app — this page is installable and works offline once loaded.

Using it without a mouse

Tab reaches every control, and the focused one is outlined in blue. From the grid, Shift+←/→ walks through the notes of the active track and Home/End jump to its first or last — each one is spoken as pitch and position (“G4, bar 1 beat 1”), so the arrow keys, Delete and the inspector all become usable from the keyboard. A skip link at the very top jumps straight to the grid.

To write notes rather than only edit the ones that exist, arm a track with its R button and use step entry (above). That also gives you a cursor you can move around the grid in both directions — ←/→ through time, ↑/↓ from track to track, Home/End to the start of the song or the end of this track's part — and every move is spoken with the position and what is already there, so you can survey a song you can't see.

Rhythm patterns

Inserts a one-bar groove into the Rhythm track, tiled from the playhead's bar through the end of the song (replacing whatever was there). Move the playhead first if you only want to fill part of the song. Every hit lands with its own velocity, so the groove has accents rather than a flat machine pulse.

Chord progressions

Writes one chord per bar into this track, from the playhead's bar through the end of the song (replacing whatever was there). The chords come from the song's key — the same progression is major or minor depending on the scale you picked, so change the key and press Insert again to hear it somewhere else entirely.
